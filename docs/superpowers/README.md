# Historical implementation notes

The plans and designs in this directory record past implementation work. They
are not build instructions or a description of the current supported products.

The native Android application, its APK build/release pipeline, and its
privilege-separated helper have been removed. App-only plans have been deleted.
Shared historical plans remain because they also document the desktop and
Termux implementations; their old app/helper snippets are historical only.

For current platforms, configuration, and build commands, use the repository
README and the current Cargo workspace. Termux remains supported.
